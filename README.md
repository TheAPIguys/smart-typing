# Logseq Smart-Type Plugin

Predictive text and intelligent autocomplete for Logseq, powered by a local SQLite learning engine.

## Features

- **Instant Autocomplete:** Suggests words as you type.
- **Smart Learning:** Learns from your usage using a local SQLite database.
- **Privacy Focused:** All data stays local.

## Development

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Build the plugin:
   ```bash
   pnpm build
   ```

3. Load in Logseq:
   - Enable Developer Mode in Logseq.
   - "Load unpacked plugin" and select this folder.
